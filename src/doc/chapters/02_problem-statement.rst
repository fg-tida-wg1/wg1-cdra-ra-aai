Core Problem
------------

*[Author: state the core problem in remote attestation for AI agents.]*

Remote attestation was designed for software whose code and configuration can be measured before it runs. An AI agent's behaviour depends on model weights, prompts, tools and retrieved data that change at run time, so a measurement taken at launch says little about what the agent will do next.
